# Code of conduct

Everyone participating in this project should be treated with respect. Welcome
questions and different experience levels. Offer specific, constructive feedback.

Harassment, threats, discriminatory language, sharing private information without
permission, and sustained personal attacks are not acceptable. Maintainers may
remove content or restrict participation when needed to protect contributors.

Report concerns privately to the repository maintainer through their GitHub
profile contact information. Reports will be handled discreetly and fairly.
